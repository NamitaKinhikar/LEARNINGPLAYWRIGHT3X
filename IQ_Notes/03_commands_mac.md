# VS Code Keyboard Shortcuts — Mac

## General

| Action | Shortcut |
|---|---|
| Command Palette | `Cmd + Shift + P` |
| Quick Open (File) | `Cmd + P` |
| Settings | `Cmd + ,` |
| Keyboard Shortcuts | `Cmd + K Cmd + S` |
| Toggle Sidebar | `Cmd + B` |
| Toggle Terminal | `` Ctrl + ` `` |
| Toggle Full Screen | `Ctrl + Cmd + F` |
| Zen Mode | `Cmd + K Z` |
| Close Editor | `Cmd + W` |
| Close Window | `Cmd + Shift + W` |

---

## Editor

| Action | Shortcut |
|---|---|
| Cut Line (empty selection) | `Cmd + X` |
| Copy Line (empty selection) | `Cmd + C` |
| Move Line Up | `Alt + ↑` |
| Move Line Down | `Alt + ↓` |
| Copy Line Up | `Shift + Alt + ↑` |
| Copy Line Down | `Shift + Alt + ↓` |
| Duplicate Selection | `Cmd + D` |
| Add Cursor Above | `Cmd + Alt + ↑` |
| Add Cursor Below | `Cmd + Alt + ↓` |
| Multi-Cursor (next match) | `Cmd + D` |
| Select All Occurrences | `Cmd + Shift + L` |
| Indent Line | `Tab` |
| Outdent Line | `Shift + Tab` |
| Go to Line | `Ctrl + G` |
| Go to Matching Bracket | `Cmd + Shift + \` |
| Toggle Comment (line) | `Cmd + /` |
| Toggle Comment (block) | `Shift + Alt + A` |
